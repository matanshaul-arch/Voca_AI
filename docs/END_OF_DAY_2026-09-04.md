# Voca AI — End-of-Day 360 Report and Delivery Plan

Date: 2026-09-04  
Audience: project owner and engineering team  
Repository: [Voca_AI on GitHub](https://github.com/matanshaul-arch/Voca_AI)

## Executive conclusion

The project has a credible technical foundation, but it is not yet an audio-quality product. The next proof point is real-speech training/evaluation, not a larger architecture.

The strongest product position is **Voca AI Speaker Intelligence**: an enrolled-speaker audio layer that produces clean PCM plus machine-readable confidence and conversation events. This is more defensible than competing as a generic denoiser because it connects isolation to transcription quality, turn-taking, classroom workflows and privacy.

## 360 findings

### Technical landscape

VoiceFilter and VoiceFilter-Lite validate enrollment-conditioned target extraction, including streaming/on-device use. ECAPA-TDNN is a practical speaker-profile baseline. TF-GridNet and related causal TSE work are upgrade candidates, but only after the smaller baseline is measured.

WebRTC APM already covers AEC, NS and AGC. AudioWorklet is the browser execution point for low-latency custom audio processing. The correct integration order is therefore AEC → light standard NS → Voca TSE → limiter → WebRTC/STT.

### Product landscape

Krisp offers voice isolation, background voice cancellation, VAD, turn prediction and interruption prediction. NVIDIA Maxine covers real-time enhancement and voice restoration. Apple's Voice Isolation is a platform-level microphone mode. LiveKit distinguishes voice isolation from background-noise suppression and exposes client/server options; Pipecat treats VAD and interruption events as first-class pipeline events.

### Strategic implication

Do not promise perfect removal of an equally loud overlapping speaker on a single microphone. Promise target-speaker prioritization with confidence-aware degradation, and offer a multi-mic mode for spatial separation.

## New product map

```text
Identity layer: enrollment → ECAPA profile → similarity/confidence
Separation layer: TSE mask → target retention → interferer attenuation
Conversation layer: target VAD → turn end → interruption/backchannel
Application layer: Teach / Meet / Broadcast / Agent / Accessibility
Trust layer: local processing → profile lifecycle → telemetry without raw audio
```

## Research sources and interpretation

- [VoiceFilter](https://arxiv.org/abs/1810.04826) and [VoiceFilter-Lite](https://arxiv.org/abs/2009.04323): enrollment-conditioned target extraction and streaming direction.
- [SpeechBrain ECAPA-TDNN](https://speechbrain.readthedocs.io/en/v0.5.15/API/speechbrain.lobes.models.ECAPA_TDNN.html) and [pretrained model card](https://huggingface.co/speechbrain/spkrec-ecapa-voxceleb): practical speaker profile baseline and model provenance.
- [WebRTC Audio Processing Module](https://webrtc.googlesource.com/src/+/main/modules/audio_processing/g3doc/audio_processing_module.md): AEC/NS/AGC placement.
- [MDN AudioWorklet](https://developer.mozilla.org/en-US/docs/Web/API/AudioWorklet): browser low-latency execution model.
- [Krisp VIVA](https://krisp.ai/developers/viva/): commercial voice isolation plus turn/interruption capabilities.
- [NVIDIA Maxine](https://developer.nvidia.com/maxine/): adjacent real-time enhancement and voice restoration.
- [Apple Voice Isolation](https://developer.apple.com/documentation/avfoundation/avcapturedevice/microphonemode/voiceisolation): platform voice-isolation precedent.
- [LiveKit noise cancellation](https://docs.livekit.io/home/cloud/noise-cancellation): practical distinction between isolation and background-noise suppression.
- [Pipecat VAD controller](https://reference-server.pipecat.ai/en/stable/api/pipecat.audio.vad.vad_controller.html): event-oriented VAD/turn pipeline precedent.
- [DeepFilterNet](https://github.com/Rikorose/DeepFilterNet): low-complexity residual enhancement reference.
- [LibriSpeech](https://us.openslr.org/12/), [VoxCeleb](https://www.robots.ox.ac.uk/~vgg/data/voxceleb/index.html), [LibriMix](https://arxiv.org/abs/2005.11262), and [WHAM!](https://arxiv.org/abs/1907.01160): data and benchmark candidates.

Vendor performance claims are directional only. Voca AI must reproduce latency and quality on a declared device matrix.

## Final session update — 2026-09-04

The approved real-data baseline was completed. LibriSpeech SLR12 (`train-clean-100`, `dev-clean`, `test-clean`), MUSAN SLR17 and SLR28 were downloaded, integrity-checked and extracted under Git-ignored `data/raw/`; provenance and hashes are recorded in `docs/DATASET_RELEASE_LOCK.md`.

The fixed `voca_real_v1` dataset contains 308 train, 40 validation and 36 test mixtures, with separate enrollment utterances and zero speaker overlap across target/interferer roles. A project-local Python 3.11.16 environment and preflight command were added.

The ECAPA run used SpeechBrain `spkrec-ecapa-voxceleb` revision `0f99f2d0ebe89ac095bcc5903c4dd8f72b367286`. After one CPU epoch, test SI-SDR improvement was `+0.515 dB` and interferer projection suppression was `23.61 dB`; target level delta was `-19.91 dB`. The result is encouraging for identity-conditioned suppression but fails the target-retention/product-quality bar and requires level-preservation loss or post-gain calibration.

Final validation: `scripts/preflight.py` passed, all 7 tests passed, manifests passed cross-split validation, and Git was clean after commit `cc1e150`. The branch is intentionally three commits ahead of `origin/main` pending the final push.
